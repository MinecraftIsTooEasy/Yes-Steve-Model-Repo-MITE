# Yes Steve Model: Model Expansion

An optional FishModLoader 3.4.2 addon for Yes Steve Model on MITE. It supplies an expanded collection of legacy-compatible player models sourced from [Yes-Steve-Model-Repo](https://github.com/Elaina69/Yes-Steve-Model-Repo), so the main YSMU mod can remain small. Expansion models are shown in the YSMU model screen under the add-on model category.

## Model Licenses

The source collection states that its creators made these models available for everyone, but it does not provide a root license. Individual model metadata and attribution remain authoritative. The addon keeps source paths, authors, and license information in the packaged notice and does not claim ownership of model resources. Models with unsupported protected formats are not included.
